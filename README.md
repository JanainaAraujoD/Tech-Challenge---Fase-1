# Tech-Challenge---Fase-1

OBJETIVO DO PROJETO: 
O objetivo deste projeto é sinalizar com antecedência quais pedidos entrarão na zona de detração para disparar ações preventivas imediatas.


APLICAÇÃO PRÁTICA:

Gatilho Automático: 
Se um pedido acumular 2 ou mais dias de atraso, o modelo classifica o cliente como "Risco de Detrator"

.Ação Preventiva no SAC: 
O sistema gera um alerta priorizado para a equipe de atendimento entrar em contato proativamente antes da entrega, alinhando expectativas.

Preservação: 
A intervenção reduz a migração para a zona de detração, resgatando clientes para a faixa de neutros/promotores (onde a taxa de recompra salta de 0% para 38%–100%).


COMO EXECUTAR O CÓDIGO:

Utilizando o Google Colab, importe a base de dados e execute o código.
